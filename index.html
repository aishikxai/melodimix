App Installation

Install Spoptify as a standalone application on your mobile phone or PC for full screen playback and quick home screen access.

If the button doesn't work, install it manually via your browser menu (choose "Add to Home Screen" on mobile Safari/Chrome, or click the Computer Monitor/Plus icon in your PC browser address bar).

About Spoptify

Spoptify is a 100% client-side, offline Progressive Web App. All files and synthesis logic are processed fully in your web browser. Absolutely no user data, telemetry, or audio files are ever uploaded or shared. Safe, ad-free, and always available offline.
